## 怎么用

1. 先看完整文章，选定一个细分行业，写清研究问题。
2. 下载并解压资料，把底稿模板复制到自己的研究项目中。
3. 按研究进度复制提示词，填入自己的行业、时间范围和资料要求。
4. 双击 `examples/valuation-demo.html`，修改教学参数，观察测算结果。
5. 保存证据来源、口径和日期，定期更新自己的判断。

GitHub 可以直接阅读 Markdown。HTML 文件请下载完整资料并解压后，用浏览器打开；两份文章的 HTML 与最新 v2 正文一致。图片依赖 assets 文件夹，请保留目录结构。
